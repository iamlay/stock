# ETL

数据采集与校验。Sprint 0 只有探针脚本，W2 起扩展为完整管道。

## 探针（验证数据源可用）

```bash
python etl/probe_eastmoney.py --code 510300
```

输出：

- `etl/out/510300_daily.csv`（日期、OHLC、成交量、成交额、振幅）
- 终端打印名称、行数、区间与校验结果

校验规则：日期升序且不重复、`high >= low`、`close` 在高低之间、价格为正。

## 设计约束

- 原始响应先落 ODS（对象存储），再解析入库，保证可重放。
- 每个数据源实现 `SourceAdapter`，主备切换只改配置。
- 不抓取需要登录、付费墙或明确禁止抓取的数据。
