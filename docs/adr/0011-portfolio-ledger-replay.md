# ADR-0011：私人流水追加更正与确定性重放

- 日期：2026-10-27
- 状态：本地采用，生产待验收
- 对应：V2-51；前置 [ADR-0010](0010-private-portfolio-ownership.md)

## 决策

财务事实采用追加流水，修改通过同账户/同股票的 `reverses_id` 关联替代；原数据不覆盖。撤销为零金额凭据，不生成反向买卖以免改变历史均价。任一目标只能直接被取消一次；替代被撤销不复活旧数据。数据库复合外键限制账户/用户，账户删除级联清理。

每次写入在账户父锁和乐观版本控制下重放所有有效流水，按生效日期与显式同日顺序检查每个中间余额。通过后原子保存流水、版本、操作审计及分红待核对范围。请求UUID和摘要限制网络重试重复记账。

成本按移动加权平均，Decimal内部计算，Numeric存储，传输和导出采用十进制字符串。规则版本 `moving-average-cny-v1` 固定6位小数、ROUND_HALF_UP，清仓移除全部剩余成本。买卖费用明确计入，不将现金股息冲减成本。

历史覆盖起点显式保留，起点前永远未知；人工调整有原因及依据、标记历史不完整。不凭当前持仓猜历史权益。V2-52必须消费核对范围并验证版本，不得静默覆写已核对收入。

当前小规模手工内测即时重放，不增加持仓缓存第二事实来源。大量CSV导入前需要性能验证及分页，必要时增加可丢弃、带流水版本的缓存。

## 隐私与后果

V2-50元数据确认不覆盖持仓与交易。提升说明版本和scope，旧账户主动确认后才允许财务写入，保留旧确认快照。本人导出/删除及恢复清单重放同步覆盖新表，基础维护不依赖会员。

当前不计算市场估值、完整收益率及自动分红，不声称联通或核实券商数据。交付接口、算例和部署详见 [V2-51说明](../V2_51_DELIVERY.md)。
