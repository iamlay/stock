# ADR-0010：私人账本单账户、确认记录与恢复清理

- 日期：2026-10-27。
- 状态：V2-50 本地实现并测试，生产待验收。
- 范围：账户元数据与隐私基础；不包含 V2-51 的持仓/交易引擎。

## 决策

1. 首版一个人民币账户，归档仍占一个账户名额；免费、试用、会员规则相同。由登录态决定所有者，拒绝客户端提交 user_id；数据库用户唯一约束与父用户行锁防并发超额。后续 V2-63 再迁移多账户规则。
2. 账户引用属于同一用户的隐私确认记录；操作记录用账户/用户复合外键约束。管理员没有私人账户读取捷径。用户数据与原管理员审计分开，操作记录只保存动作、版本和时间，不保存账户名称前后值。
3. 首次建立账户前必须展示服务端当前版本说明并主动确认，服务端校验版本和 SHA-256，事务内保存说明快照、确认时间和账户。不默认勾选，不接受旧说明，不从自选生成账户。当前说明仅授权账户元数据；V2-51 开放持仓前必须更新说明并取得相应确认。
4. 基础维护、归档、恢复、导出、删除不依赖会员；关闭创建开关后，已有数据仍可访问和维护。并发更新或删除需当前版本号；未归属对象和不存在对象均返回相同 404。
5. 私人 API 成功、认证失败、参数错误、限流和对象不存在响应均不允许缓存；参数错误不回显原始输入。导出为 JSON，固定文件名，不把用户名称放入 URL、CSV 或下载文件名。当前导出仅账户元数据，不伪称已提供完整持仓账本。
6. 私人页面排除百度/Vercel 统计组件。入口使用整页导航；若客户端仍有既存统计脚本/全局对象，先刷新文档再取私人数据。跨页缓存、账号切换及迟到请求须清除/忽略旧账户信息；不存本地名称草稿，不发自定义分析事件。
7. 删除移除在线账户与私有操作记录，保留不含名称的最小确认和删除凭据。删除凭据不能以账户外键级联删除。恢复旧备份时需要独立保存的最新删除清单重放；重放校验全部所有权后才删除，重复执行无副作用，不误删后来新建的不同 UUID 账户。
8. 当前删除清单由运维工具导出及重放，并未自动同步到异地存储。开启真实内测前要落实独立加密保管及恢复流程，无法取得最新清单时保持私人功能关闭。不能仅把凭据存在同一旧备份里就宣称恢复后删除得到保证。
9. 新功能默认关闭，可按用户 ID 白名单开放创建；V2-48 数据业务门槛、V2-44 业务事件及 V2-46 到期治理仍按主计划验收。V2-50 不开启个人应收或自动到账。
