# ADR-0013：已收录历史分红参考

日期：2026-10-28。状态：本地实现，生产待验。修订 ADR-0012 第9项的历史参考限制，不改变持仓财务规则或应收/实收门槛。

## 问题

原持仓页只读取事件版本库，未接入股票详情的 StockDividend；且历史年均固定返回未知。用户已有可用分红和报价仍无法查看参考息率。

## 决策

1. 已核对的当前事件版本优先于关联历史行；未核对回填不覆盖关联的最新历史行。无关联的已核对事件以报告期+除息日匹配，取消且缺除息日仅匹配相同报告期和方案。无法确认的冲突保留待核对。
2. 窗口为 `(基准日−12/36/60个月, 基准日]`，以除息日归窗。有效普通现金记录合计固定除以1/3/5；同报告期不同除息日均保留，相同报告期和除息日相同金额去重，金额冲突不猜测。
3. 未实施、取消、不分配、特别/一次性分红不计入普通参考；缺日期/金额、未知阶段、正数送转、上市时间不足或冲突阻断。旧库无阶段但有除息日的记录允许作为未核验历史参考，并在明细区分。
4. 不声称完整覆盖：`coverage_verified=false`。缺记录年度金额返回null，注明未收录不等于零；存在有效记录时仍可展示固定窗口的已收录金额参考。没有有效记录不自动输出0；明确自定义0合法。不向前寻找更久记录补窗口。
5. 年度金额为当前数量×年度每股参考；价格股息率为每股参考÷价格×100。行情表优先，指标表价格回退注明“行情快照更新时间”，不伪装为报价时刻。无报价与无分红原因分别展示。
6. 预览摘要包括来源与计算结果；确认时重算并校验摘要，数据更新后要求重新预览。所有金额由服务端Decimal计算，前端不另算财务值。
7. 不写公共数据、不新增数据库迁移、不生成应收实收；完整覆盖认证、公司行动调整和真实样本核验仍是后续工作。

## 验证

新增回归覆盖窗口边界、闰日、固定分母、缺数据与自定义零、重复与冲突、当前修订优先、旧回填不覆盖新数据、报价回退和预览依据变化。浏览器验收使用隔离临时数据库中的合成数据。
