# 持仓详情 · 交易明细交付

日期：2026-10-31。状态：本地实现、测试与构建通过；生产待验收。

## 已交付

`/portfolio/[code]` 持仓详情新增独立「交易明细」模块：

- 按日期倒序展示；
- 显示交易类型、日期、数量、价格、费用、成本或收入；
- 支持买入、卖出、送股、分红复投、已有持仓快照、修正、撤销；
- 点击「编辑」进入更正；
- 点击「删除」生成冲正凭据，不删除原记录；
- 底部「+ 添加交易」。

顶部快捷按钮：

```text
买入
卖出
送股
分红复投
```

## 新增交易类型

```text
bonus     送股
reinvest  分红复投
```

口径：

```text
送股：数量增加，总成本不变，平均成本摊薄
分红复投：数量增加，不追加投入，总成本不变
```

两者不填写成交价，不产生交易费用。
