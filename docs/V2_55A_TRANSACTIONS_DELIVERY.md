# 持仓详情 · 交易明细交付

日期：2026-10-31。状态：本地实现、测试与构建通过；生产待验收。

## 已交付

`/portfolio/[code]` 持仓详情按原型改为模块入口：

```text
交易明细      + 添加
分红记录      查看 / 添加
历史分红回溯  待开发
编辑持仓
分红档案
删除持仓      待开发
```

交易明细不再直接铺在详情页，点击进入：

```text
/portfolio/{code}/transactions
```

交易明细页：

- 按日期倒序展示；
- 显示交易类型、日期、数量、价格、费用、成本或收入；
- 支持买入、卖出、送股、分红复投、已有持仓快照、修正、撤销；
- 点击「编辑」进入更正；
- 点击「删除」生成冲正凭据，不删除原记录；
- 底部「+ 添加交易」进入录入页。

录入页顶部用 Tab 切换：

```text
买入 | 卖出 | 送股 | 分红复投
```

持仓详情页不再直接放买入、卖出、送股、分红复投按钮，避免绕过交易明细页。

## 新增交易类型
```text
bonus     送股
reinvest  分红复投
```

口径：

```text
送股：数量增加，总成本不变，平均成本摊薄
分红复投：数量增加，不追加投入，总成本不变
```

两者不填写成交价，不产生交易费用。

## 持仓详情汇总

详情页新增：

```text
累计已获分红
分红回本进度
净投入
已收回分红
剩余待回收
按当前年度分红参考预计回本
```

累计分红来自 V2-53 有效到账记录（净额）；回本进度按“摊薄成本”口径计算，不等于累计买入金额。
