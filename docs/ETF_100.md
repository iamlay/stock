## 3. 生产启用步骤

### 1. 部署 API/Web

API 和 Web 都使用同一份代码，部署后先执行数据初始化。

### 2. 初始化 ETF 池

```bash
python -m etl.cli seed
```

### 3. 补历史日线

新加的 80 只需要历史数据：

```bash
python -m etl.cli sync-all --start 2016-01-01 --delay 0.2
```

已有 20 只会按窗口覆盖，不会重复。

### 4. 补份额 / 估值

```bash
python -m etl.cli sync-shares
python -m etl.cli sync-valuation
```

### 5. 刷新最新报价

```bash
python -m etl.cli sync-quotes --force
```

### 6. 验证

```bash
curl "https://stock-production-c535.up.railway.app/api/v1/etfs" | jq '.value | length'
```

应为 100。

## 5. 已知限制

- 估值分位只对已有指数映射的 ETF 有值，其余显示 `—`；
- 债券/货币 ETF 没有 PE/PB，属于正常；
- 100 只日线全量同步比 20 只慢，建议一次跑完；
- 5 分钟报价 100 只仍可批量，但请求体更大；
- 新增 ETF 的跟踪指数需要人工补 `VALUATION_INDEX` 才能显示 PE 分位。
