# 个股行业数据源 Phase 0 验证报告

> 日期：2026-10-20
> 目标：为全市场个股模块确定行业字段来源
> 结论：**Eastmoney F10 可作主源，但只能按需/分批；Sina 行业节点可批量但只覆盖约 56%。**

---

## 1. 验证结果

| 源 | 覆盖 | 字段 | 结论 |
|---|---|---|---|
| Eastmoney F10 `CompanySurvey` | 15/15 样本 | 东财行业三级、证监会行业、板块、上市日 | ✅ 主源 |
| Sina 行业节点 `getHQNodes` + `getHQNodeData` | 2,927 / 5,217 | 一级行业名 | ⚠️ 兜底，覆盖不全 |
| Eastmoney clist `f100` | 当前网络被断连 | 行业 | ❌ 暂不可用 |

## 3. Sina 行业节点

接口：

```text
getHQNodes                 → 49 个行业节点
getHQNodeData?node=...     → 每个行业的股票列表
```

结果：

```text
行业节点：49
映射股票：2,927 / 5,217（约 56%）
样本覆盖：15 / 15
```

特点：

- 可批量，不需要逐只请求；
- 只有一级行业（如“金融行业”“家电行业”“酿酒行业”）；
- 分类较粗，且覆盖不全；
- 适合作为初始粗分类，不适合作为唯一来源。

---

## 4. 两个源的口径差异

同一只股票：

```text
600519
  Sina:      酿酒行业
  Eastmoney: 食品饮料-饮料-白酒

601398
  Sina:      金融行业
  Eastmoney: 金融-银行-国有银行
```

Sina 是一级行业，Eastmoney 是三级行业。不能直接混用做筛选，需要确定展示口径。

---

## 5. 推荐方案

### 展示口径

- 列表筛选：使用 **Eastmoney 一级行业**（`EM2016` 第一段）；
- 详情页：展示完整 `EM2016` 三级路径；
- 同时保留证监会行业作为辅助字段。

### 数据来源

| 场景 | 来源 |
|---|---|
| 用户查看/添加自选 | Eastmoney F10，实时补 |
| 全市场初始粗分类 | Sina 行业节点，批量导入 |
| 全市场精确补全 | Eastmoney F10，分批后台任务 |
| Eastmoney 列表可用时 | clist `f100`，优先批量 |

### 覆盖策略

不要阻塞上线等 100% 行业覆盖：

1. 首版允许 `industry = "未分类"`；
2. 行业筛选只对有行业的股票生效；
3. 优先补 500 只灰度股票；
4. 后台每天补 300–500 只，约 10–15 天补齐；
5. 用户查看/添加的股票立即补。

---

## 6. Phase 1 数据模型调整

`stock_profiles` 增加：

```text
industry          varchar(32)   一级行业，用于筛选
industry_path     varchar(128)  完整三级路径
industry_source   varchar(16)   eastmoney / sina / null
industry_updated_at timestamptz
```

`stock_metrics` 不变。

---

## 7. 风险

| 风险 | 应对 |
|---|---|
| F10 逐只请求被限流 | 限速 2–5 req/s、重试、断点续跑 |
| gzip 响应解码失败 | 已加 gzip/deflate 解码 |
| Sina 覆盖只有 56% | 只作粗分类，缺失走 F10 |
| 两套行业口径混用 | 统一展示东财一级，Sina 仅兜底 |
| 行业变更 | 季度全量刷新 + 按需更新 |

---

## 8. 结论

- 行业数据源**可行**；
- Eastmoney F10 质量最好，但不能全市场实时逐只拉；
- Sina 可批量但覆盖不足；
- Phase 1 采用“**Sina 粗分类 + Eastmoney 按需/分批补全 + 未分类兜底**”；
- 行业筛选首版只对已分类股票生效，不阻塞核心股息率排序上线。
